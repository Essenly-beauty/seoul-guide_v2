## 판정을 가른 신호 — 공개 API

다이소몰은 상품의 **판매 옵션 목록**을 JSON으로 돌려준다. 화면을 긁지 않고 이것으로 판정했다.

```bash
curl -s -X POST https://fapi.daisomall.co.kr/pdo/pdOptRevwCnt \
  -H 'Content-Type: application/json' -H 'Referer: https://www.daisomall.co.kr/' \
  -d '{"pdNo":"1055168"}'
```

응답의 `data` 배열이 그 상품의 판매 구성이다. **길이 1 = 고정 구성, 2 이상 = 선택형.** 같은 방식으로 `.../pd/pdr/pdDtl/selPdAttr` 가 분류 코드와 속성을 준다.

**26건 전부 `data` 길이가 1이었다.** 다이소 후보에는 옵션 선택형이 없다. 이것이 올리브영과 크게 다른 점이다(올리브영은 16건 중 6건이 옵션형).

> 이 두 엔드포인트는 브라우저 없이 `curl`로 열린다. 다이소 쪽 후속 검증은 헤드리스 브라우저를 띄울 필요가 없다.
