# 리뷰 후속 검증 — 2026-10-09

## 실제 Chrome에서 확인한 동선

`ae02c37`의 로컬 프로덕션 빌드를 127.0.0.1:3017에서 실행하고 연결된 Chrome으로 검증했다. 운영 계정·DB에는 쓰지 않았다.

- 비회원 장소 상세 접근: 장소 정보와 길찾기 표시.
- 별점 4개 클릭: 로그인 안내 표시, 작성 폼 없음.
- 안내 닫기: 별점은 0으로 유지되며 탐색 화면 복귀.
- Write a review 클릭: 동일한 로그인 안내 표시.
- 로그인 링크: 해당 장소로 돌아오는 `next` 경로 포함.
- 리뷰 편집 URL 직접 접속: 로그인 안내와 Browse the map만 표시, 작성 폼 없음.
- 내 리뷰 목록: 로그인 안내와 지도 이동 링크 표시.

이 결과는 이전 기록의 '브라우저 검증 미완료' 중 비회원 기본 화면 검증을 보완한다. Playwright 자동 테스트 통과를 뜻하지 않는다. 기존 기기 기록이 있는 브라우저와 실제 로그인 계정 저장/공개는 아직 화면 검증하지 않았다. 로컬 빌드는 검증용 공개 환경값을 사용하므로 공개 리뷰 서버 읽기도 검증 대상이 아니었다.

## 추가 수정: 로그아웃과 늦은 응답 순서

`lib/ratings.ts`의 초기 `getUser()` 응답이 로그아웃 이벤트 뒤에 도착하면 이전 계정을 다시 저장 모듈에 설정할 수 있었다. 지연 응답을 사용한 테스트에서 비회원 저장이 거절되지 않는 것을 재현했다.

실제 인증 변경 이벤트 이후에는 초기 조회 응답과 오래된 INITIAL_SESSION 재생을 무시하도록 수정했다. 서버 권한 우회나 운영 데이터 노출을 재현한 것은 아니다. 클라이언트 저장 상태의 순서 문제다.

- 관련 테스트 13개 통과(인증 테스트 7개 포함).
- 타입 검사 통과.
- 원격 main의 후속 변경은 카페 조사 자료 3개 파일뿐이다. 리뷰 변경은 원격 main에 아직 포함되지 않았다.
