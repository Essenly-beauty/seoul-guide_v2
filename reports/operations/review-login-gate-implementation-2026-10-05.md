# 별점·리뷰 로그인 제한 구현 기록 — 2026-10-05

## 반영한 정책

- 장소 탐색, 장소 상세와 공개 리뷰 읽기는 비회원에게 공개한다.
- 별점과 리뷰 글의 작성·수정은 로그인 후 가능하다.
- 별점을 선택하면 같은 작성 영역에서 선택적 리뷰 글을 함께 입력하고 저장한다. 글 없이 별점만 저장할 수 있다.
- 신규 리뷰의 공개 체크는 기본 해제한다. 기존 공개 리뷰를 편집할 때는 그 선택을 유지한다.
- 비회원이 별점이나 리뷰 작성 버튼을 누르면 로그인 안내를 표시하며 입력을 저장하지 않는다.
- 내 리뷰 목록·상세·편집 주소로 직접 들어와도 비회원에게 개인 리뷰와 작성 폼을 노출하지 않는다.
- 저장 함수에서도 로그인 상태를 검사한다. 로그아웃 후 열린 작성 화면에서 저장을 시도해도 거절한다.
- 예전 비회원 기기 기록은 삭제하지 않는다. 로그인 후 이관되는 리뷰 글은 비공개로 강제한다.

## 구현 순서와 근거

1. 비회원 별점·리뷰 저장과 이전 공개 플래그 이관을 재현하는 테스트를 추가했다. 기존 코드에서 해당 3개 테스트가 실패하는 것을 확인했다.
2. `lib/ratings.ts`에 로그인 필수 저장 결과와 별점 유효성 검사를 추가하고, 이전 기기 기록 이관 시 공개 플래그를 제거했다.
3. 장소 상세의 즉시 별점 저장을 별점+선택적 글의 공동 저장 흐름으로 변경했다.
4. 내 리뷰 화면의 로그인 안내, 직접 주소 접근 제한, 계정 변경 시 작성 내용 초기화를 연결했다.
5. 기존 공개 리뷰 E2E의 신규 공개 동의 단계를 갱신하고 비회원 진입 E2E 3개를 추가했다.

## 검증 결과

- `npm test`: 102개 파일, 971개 테스트 통과. 인증 관련 신규 동작 테스트 6개 포함.
- `npm run typecheck`: 통과.
- `npm run lint`: 오류·경고 없음. Next CLI 자체의 기존 deprecation/workspace 안내는 출력됨.
- `npm run build`: 통과, 정적 페이지 45개 생성. 로컬 검증용 공개 환경값으로 수행했으며 운영 인증을 사용하지 않았다.
- `git diff --check`: 통과.
- 브라우저 E2E: 미검증. 포트 3001이 사용 중이어서 독립 서버 3017로 분리했다. 시스템 Chrome과 Playwright Chromium 모두 브라우저 시작 시 SIGABRT/EPERM으로 종료되어 3개 테스트의 화면 동작까지 도달하지 못했다. 테스트 실패를 앱 기능 실패나 통과로 해석하지 않는다.
- 로그인 사용자 저장 동작은 모의 Supabase를 사용한 저장 함수 테스트로 확인했다. 실제 운영 계정으로 로그인/리뷰 게시하는 검증은 수행하지 않았다.

## 인계와 남은 작업

작업 브랜치: `feat/review-auth-gate-20261005`.

브라우저가 실행 가능한 환경에서 다음을 수행한다.

```sh
E2E_EXTERNAL_ONLY=1 E2E_BASE_URL=http://127.0.0.1:3017 npm run e2e -- e2e/review-login-gate.spec.ts
```

대상 서버에는 정상적인 공개 Supabase 환경값이 필요하다. 비회원 테스트는 운영 계정을 생성하거나 리뷰를 게시하지 않는다. 이어서 별도 테스트 계정으로 별점만 저장, 글과 별점 저장, 공개 선택, 로그아웃 후 작성 차단을 확인한 후 배포한다.

운영 DB·스키마·배포 변경 없음. `public_reviews` 보안 경고와 `Member` 작성자명 처리 변경은 기존에 정리한 별도 DB 작업으로 남아 있다. 이 커밋이 그 문제를 해결했다고 간주하면 안 된다.
