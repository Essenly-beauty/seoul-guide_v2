# 계정 데이터 다운로드 오류 처리 — 2026-09-27

## 수정한 범위

- 기존 다운로드는 `favorites`, `ratings`, `profiles` 중 한 조회가 실패해도 `null`을 빈 배열/값으로 바꿔 성공 파일을 내려줬다.
- 이제 세 조회 중 하나라도 오류가 나거나 즐겨찾기·평점 컬렉션이 예상치 못하게 `null`이면 파일을 만들지 않고 `503`과 재시도 안내를 반환한다. 조회 예외와 인증 확인 오류도 같은 방식으로 처리하고 내부 오류 문구는 응답에 넣지 않는다.
- 정상 파일과 오류 응답 모두 `private, no-store`이며, 오류 응답에는 다운로드 첨부 헤더가 없다. 비회원은 여전히 `401`이고 개인 테이블을 조회하지 않는다.
- 이 변경은 **다운로드 내용의 범위를 넓히지 않는다.** 현재 성공 파일은 계정 기본 정보, 뷰티 프로필, 즐겨찾기, 평점/리뷰 본문만 담는다.

## 검증과 남은 결정

- 새 테스트 8건: 정상, 각 조회 실패 3종, 예외, 예상 밖 null, 인증 오류, 비회원. 실패하는 테스트를 먼저 확인한 뒤 수정했다.
- 전체 `npm test` 964건, 타입 검사, 린트, CI와 같은 공개 환경값의 프로덕션 빌드가 통과했다.
- 실제 회원 계정의 다운로드 내용과 타인 자료 분리는 아직 라이브에서 검증하지 않았다. 이 브랜치를 운영에 반영하기 전에 테스트 계정으로 확인해야 한다.
- 공유목록, 리뷰 공개 상태(`is_public`/`hidden`), 가입·마케팅 동의, 피드백 등은 현 파일에 없다. 어떤 항목을 제공하고 익명 피드백을 어떻게 취급할지는 별도 범위·개인정보 검토가 필요하다. 현재 화면의 ‘내 데이터 다운로드’를 완전한 전체 데이터 사본으로 설명하면 안 된다.
