## 역 검색 전용 화면

실제 `/map?mode=subway`의 출발지·도착지 버튼을 누르면 앱 영역 전체를 차지하는 검색 화면으로 전환된다. 경유지 추가에도 같은 검색을 쓴다. URL을 바꾸는 별도 Next 페이지가 아니라 기존 경로 편집 상태를 보존하는 앱 내 화면이다.

- 상단 뒤로가기 + 작은 왼쪽 제목 + 검색창. 아래 결과 목록만 스크롤.
- 영문·한글·기존 별칭(Hongdae 등) 검색. 기존 검색 엔진의 순서를 유지하며 8개 드롭다운 제한을 없앰.
- 검색 전에는 주변 역/최근 역/주요 역을 중복 없이 제공. 위치 권한 거부 시에도 검색 가능.
- 목록은 영문 역명, 작은 한글명, 노선 색상/번호 배지. 검색 결과 없음을 명확히 표시.
- 검색어 입력/지우기는 기존 경로 값을 변경하지 않음. 결과 선택 시에만 출발/도착/경유지를 변경. 화면 내 뒤로가기·Escape 취소 시 기존 선택 유지. 선택 역 삭제는 별도 Remove action.
- 키보드 방향키/Enter, 한글 IME 입력 중 Enter 보호, 포커스 복귀 및 Tab 순환. 모바일 키보드 높이 변수로 화면 하단 조정.
- 기존 출발/도착 교환, 경유 순서, 동일 역 차단, 경로 미리보기 및 외부 지도 전달 로직 보존. 실시간 운행 API를 새로 연결하지 않음.
