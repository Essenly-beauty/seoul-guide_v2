- **오너가 먼저 하는 일**: 대시보드 토글·결제·도메인·법무 승인·운영 책임자처럼 계정 소유권이나 사업 판단이 필요한 일. 비밀값은 채팅·문서·Git에 남기지 않는다.
- **제가 이어서 하는 일**: 승인된 정책을 UI/코드/문서에 반영하고, 테스트 계정만 사용해 프로덕션 흐름을 검증하며, 결과와 되돌리기 방법을 남긴다.
