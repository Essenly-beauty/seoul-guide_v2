# Essenly 서비스 현황

> 기준 커밋: `563950d` · 기준일: 2026-07-26 · 단계: 프론트엔드 제품 프로토타입

## 1. 서비스 정의

Essenly는 한국을 방문한 외국인이 서울에서 뷰티 관광을 계획하고 현장에서 이동할 때 사용하는 영어 중심 모바일 웹 서비스다.

핵심 문제는 다음 세 가지다.

1. 외국인이 신뢰할 수 있는 클리닉, 헤어, 네일, 퍼스널컬러, 헤드스파, K-뷰티 쇼핑 장소를 찾기 어렵다.
2. 매장명·주소·예약 채널이 한국어 중심이라 검색과 현장 의사소통이 어렵다.
3. 지하철 이동과 역 주변 뷰티 장소 탐색이 별도 서비스에 흩어져 있다.

현재 제품은 이 문제를 검증하기 위한 클라이언트 UX를 구현했다. 운영 인증, 검증된 장소 DB, 예약·결제 및 실시간 재고는 아직 연결하지 않았다.

## 2. 대상 사용자

### 핵심 사용자

- 서울을 처음 또는 짧게 방문하는 외국인 여행자
- 한국에서 피부관리, 헤어, 네일, 퍼스널컬러, 헤드스파를 경험하려는 사용자
- Olive Young 등에서 K-뷰티 제품을 비교하고 구매하려는 사용자
- 한국어 주소와 상호명을 현지 직원·기사에게 바로 보여줘야 하는 사용자

### 핵심 사용 상황

- 현재 위치 1km 안의 뷰티 장소를 빠르게 확인
- 출발역·경유역·도착역을 정하고 경로의 역을 순서대로 탐색
- 선택한 역으로 지도를 이동하고 역 주변 장소를 거리순으로 확인
- 영어명으로 검색한 뒤 한국어 상호·주소를 복사
- 외부 지도 앱으로 실제 길찾기
- 제품을 피부 타입·고민 기준으로 탐색하고 판매 가능 장소로 이동

## 3. 현재 정보 구조

하단 탐색은 다섯 개 탭으로 고정한다.

| 탭 | 역할 | 대표 경로 |
|---|---|---|
| Map | 현재 위치·역 기준 장소 탐색과 지하철 경로 | `/map` |
| Stories | 서울 뷰티 가이드 콘텐츠 | `/blog` |
| Ranking | 제품·브랜드 랭킹 | `/ranking` |
| Saved | 장소·제품·글 즐겨찾기 | `/favorites` |
| My | 프로필·예약·리뷰·설정·지원 | `/menu` |

로그인 화면은 `/`에 있지만 현재 모든 로그인 방법과 게스트 진입이 `/map`으로 직접 이동한다. 인증과 세션은 구현되지 않았다.

## 4. 핵심 사용자 여정

### A. 현재 위치에서 장소 찾기

1. `/map` 진입
2. 위치 권한 사용 또는 Gangnam Station 기본 위치 사용
3. 카테고리와 상세 필터 선택
4. 지도 범위 재검색 및 거리순 목록 확인
5. 목록 행 선택
6. 선택 마커가 지도 뷰 중앙으로 이동하고 큰 장소 콜아웃 표시
7. 장소 상세 또는 외부 지도 길찾기로 이동

### B. 지하철 경로와 역 주변 탐색

1. `/map`에서 Subway 모드 선택
2. 영어·한국어 역 검색으로 출발/경유/도착 설정
3. 환승을 포함한 경로 요약 확인
4. 하단 역 스트립에서 활성 역 이동
5. 지도가 해당 역으로 이동
6. 500m/1km/2km 직선 반경의 장소를 카테고리별 확인

지리 지도에는 지하철 노선이나 역 사이 경로를 그리지 않는다. 경로 정보는 하단 컨트롤러가 담당하고, 지도는 선택 역 주변 장소 이해에 집중한다.

### C. 통합 검색

1. 영어 또는 한국어로 장소·제품·글 검색
2. 이름·태그·거리 기반 결과 확인
3. 장소 결과 선택 시 `/map?place=<id>`로 복귀
4. 지도 중앙에 선택 장소 표시

검색 대상은 현재 샘플 데이터로 제한된다. 주소 지오코딩, 오타 교정, 서버 검색은 없다.

### D. 장소 상세와 현장 이동

1. 장소 개요·서비스·가격·리뷰·주변 장소 확인
2. 한국어 상호와 주소 복사
3. 택시 기사에게 보여줄 정보 확인
4. Google/Naver/Kakao 지도 링크로 이동

전화, 웹사이트, SNS, 사진, 리뷰 및 예약 채널 일부는 공통 샘플 또는 토스트 동작이다.

### E. 제품 탐색

1. `/ranking`에서 판매/리뷰/브랜드 기준 탐색
2. 제품 상세에서 브랜드, 분류, 피부 타입, 고민 확인
3. 주변 판매점 지도 또는 루틴으로 이동

제품 14개는 추천 UX 검증용 데이터다. 실제 Olive Young 랭킹, 가격, 성분, 지점별 재고 및 검증된 온라인 구매 링크와 연결되지 않았다.

## 5. 제품 원칙

- 지도는 한 번에 하나의 중심을 명확히 보여준다.
- 목록 선택과 역 선택은 항상 현재 지도 뷰 중앙 이동으로 연결한다.
- 역 주변 기본 범위는 1km이며 500m/2km로 변경할 수 있다.
- 거리는 보행 경로가 아닌 직선거리임을 명시한다.
- 영어 탐색을 우선하되 한국어 원문 상호·주소를 보존한다.
- 확인되지 않은 영업시간, 가격, 재고, 예약 성공을 사실처럼 표시하지 않는다.
- Daiso처럼 데이터가 없는 카테고리는 결과를 조작하지 않고 외부 검색 대안을 제공한다.
- 지도·예약·결제처럼 실패 비용이 큰 행동은 명시적인 상태와 복구 경로를 제공한다.
