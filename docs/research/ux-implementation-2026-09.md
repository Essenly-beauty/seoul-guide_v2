## 2. 구현 메모 (보정안이 원안과 다른 지점)

- **R1**: 눌림 규칙은 `@layer base`가 아니라 **파일 말미**. `@layer base`에 두면 `.chip{background:transparent}`(:1683)에 진다. reduced-motion 블록(:248-253)은 `transition:none`이라 `scale()`이 즉시 점프로 남으므로 같은 블록에 `transform:none`을 추가해야 한다. `.btn`은 배경 대신 `filter: brightness()` — 기존 `transition` 단축형이 base transition을 지우기 때문.
- **R2**: 가려지는 높이는 76/78px이 아니라 **≥80px**(`min-height`가 :5662에서 최종 승리). 회귀 테스트 `lib/subway-search-layout.test.ts:321-326`이 `bottom: 0;` 문자열을 고정하므로 같은 커밋에서 재타깃.
- **R3**: 패널을 **이동**시키면 `.map-screen{overflow:hidden}` 때문에 입력 필드가 잘린다. `max-height`로 **축소**해야 한다. 훅은 rAF 병합 + `vv.scale > 1`이면 인셋 0.
- **R6**: `animationend` 게이팅은 **금지**. reduced-motion에서 `animation:none !important`라 이벤트가 영영 오지 않아 시트가 닫히지 않는다. 타이머 기반 + `matchMedia`는 effect 안에서 읽는다.
- **R7**: `dragMoved`는 고무줄 통과 위치가 아니라 **릴리즈 시점의 최대 손가락 이동량**으로 판정. 감쇠 0.55 때문에 위치 기준은 빠른 플릭을 놓친다.
- **R8**: 기존 계약 테스트 정규식 `[\s\S]*?`는 규칙 블록을 넘어 매칭되어 mutation test에서 무력함이 확인됨 → `[^}]*`로 교체.

## 3. 진행 기록

### 완료 (커밋 8개, 테스트 749 → 827)

모두 TDD로 진행했다. 계약 테스트를 먼저 실패시키고, 구현 후 통과를 확인했다.

- **V0** — `useReportWebVitals`가 Next.js 자체 타이밍(`Next.js-hydration` 등)까지 넘겨 매 페이지 로드마다 400이 찍히고 있었다. 지난 배치에서 내가 만든 회귀이며, 이번 계측이 잡았다.
- **R1** — 눌림 규칙을 파일 말미(언레이어드)에 두어 `.chip{background:transparent}`를 이긴다. `touch-action: manipulation`은 본문이 아닌 `button/a/[role=button]`에만 걸어 더블탭 줌 어포던스를 남겼다.
- **R2** — 스테퍼는 이미 스크롤러 **바깥**의 형제라 절대배치만 제거하면 됐다(JSX 변경 0). 2026-08-22 결정(바닥·엄지존·스크롤 안 됨)은 그대로 유지된다.
- **R8** — 5계열 + 추가 발견 2건을 44px로. 스냅 핸들은 가시 높이를 유지한 채 `::before`로 히트영역만 확보해 크롬 예산을 깨지 않았다.
- **R3** — `--kb` 훅. 패널을 **축소**한다(이동하면 `.map-screen{overflow:hidden}`에 입력 필드가 잘린다). 결과 목록의 240px 하한도 실제 남은 공간으로 캡했다.
- **R6** — 타이머 기반 언마운트. `animationend`는 reduced-motion에서 영영 오지 않아 시트가 안 닫히는 출시 차단급 행업이 된다.
- **R7** — 슬롭 8px + 릴리즈 시점 판정. 고무줄 감쇠(0.55) 때문에 위치 기준은 빠른 플릭을 놓친다.
- **G0** — 신고된 헤더는 `padding` 단축 속성이 좌우를 0으로 덮어쓴 회귀였다(1df220d). `padding-block`으로 좁혀 16px이 내려오게 했다.

### 남은 것

- **R6 잔여** — 필터·피드백·로그인 넛지 시트는 부모가 조건부 마운트한다. 퇴장 애니메이션을 주려면 부모가 open 상태를 들고 있어야 하고, FilterSheet의 draft 상태가 그 사이 초기화되지 않아야 한다. 리스크 대비 이득이 작아 이번에 넣지 않았다.
- **R5 뒤로가기** — 미착수. `pushState`는 제스처 태스크 안에서 호출해야 iOS 엣지스와이프가 popstate를 준다는 제약, React StrictMode 이중 호출, Next 15가 `replaceState`로 history.state를 다시 쓰는 문제까지 겹쳐 네비게이션 회귀 위험이 가장 크다. 실기기 확인을 전제로 별도 진행 권장.
- **R4 지하철 그립** — 2026-08-22 스펙이 시트 통합을 post-beta로 예약. 오너 판단 필요.
- **R9~R14** — 리뷰 문서 §3의 미검증 하위 항목.
