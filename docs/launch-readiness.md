> 기준 커밋: `563950d` · 현재 단계: 프론트엔드 UX 프로토타입

## 상태 기준

| 상태 | 의미 |
|---|---|
| 미착수 | 화면 또는 계획만 있고 운영 구현이 없음 |
| 프로토타입 | 고정 데이터, 로컬 상태 또는 토스트로 UX만 검증 |

## 출시 게이트

아래 항목이 모두 충족되기 전에는 서비스를 `운영 출시 완료`로 표시하지 않는다.

1. P0 각 항목의 담당자, 완료 증거, 장애 대응 방법이 기록돼 있다.
2. 첫 출시 역·지역의 장소와 핵심 정보가 사람 검수까지 완료됐다.
3. 인증부터 예약·결제·취소·알림까지 실제 계정 E2E가 통과한다.
4. 재고가 없는 상황과 데이터가 오래된 상황을 UI가 정직하게 표현한다.
5. 실제 외국인 사용자가 한국 현장에서 길찾기와 매장 의사소통을 완료한다.
6. 약관·개인정보·의료/광고 표현이 출시 국가 기준으로 승인됐다.
7. CI, 모니터링, 지원 채널, rollback 절차가 운영 가능하다.

## 다음 실행 순서

1. 첫 출시 지역·역과 제공 카테고리를 확정한다.
2. 장소/상품 데이터 스키마와 검증 운영을 먼저 구축한다.
3. 인증·동의·계정 기반을 연결한다.
4. 예약을 외부 위임할지 직접 거래할지 결정하고 한 경로만 완성한다.
5. 핵심 E2E와 실제 외국인 현장 QA를 통과시킨다.
6. 운영·법무·모니터링 게이트 승인 후 제한 공개한다.
