# Essenly 주요 결정과 작업 이력

> 기준 커밋: `563950d` · 이 문서는 현재 구조에 영향을 준 결정을 요약한다.

## 1. 현재 유효한 제품 결정

| 결정 | 이유 | 현재 반영 |
|---|---|---|
| 홈을 별도 대시보드가 아닌 지도로 구성 | 현장 사용자는 설명보다 주변 장소 확인이 우선 | `/` 진입 후 `/map`, 하단 첫 탭 Map |
| 지도와 정렬 목록을 한 화면에서 연결 | 장소 비교와 공간 이해를 왕복 없이 수행 | 목록 선택 시 지도 중앙 이동과 큰 콜아웃 |
| 지리 지도에 지하철 노선 경로를 그리지 않음 | 장소 마커와 교통 경로가 겹치는 정보 과부하 방지 | 경로는 하단 컨트롤러, 지도는 활성 역 주변 장소 |
| 역을 출발·경유·도착 구조로 검색 | 여행자의 실제 경로 계획과 일치 | 한/영 역 검색, 순서 변경, swap, 경유역 |
| 활성 역을 이동하면 지도도 함께 이동 | 경로를 따라 역별 뷰티 장소를 탐색 | 역 스트립/마커 이동과 지도 fly 연동 |
| 역 주변 기본 범위를 1km로 설정 | 여행자가 걸어서 접근 가능한 범위를 우선 | 500m/1km/2km 선택, 직선거리 표기 |
| 장소 선택 시 선택 위치가 뷰 중앙 | 목록과 지도 사이의 선택 상태를 명확히 전달 | `?place=` 딥링크와 카메라 중심 보존 |
| 한국어 상호·주소 복사를 핵심 행동으로 제공 | 매장 직원·택시 기사와의 현장 소통 지원 | 장소·제품 상세의 Copy와 taxi 정보 |
| 확인되지 않은 재고를 표시하지 않음 | 여행 중 잘못된 구매 안내의 비용이 큼 | 온라인 구매 disabled, 지점 재고 미제공 |
| Daiso 데이터가 없으면 빈 상태를 유지 | 가짜 결과보다 외부 검색 대안이 안전 | Daiso 0건 + Naver 검색 대안 |
| 공통 UI를 디자인 시스템으로 강제 | 화면별 수작업 조립과 접근성 회귀 방지 | `/design`, UI 컴포넌트, 계약·렌더 테스트 |
